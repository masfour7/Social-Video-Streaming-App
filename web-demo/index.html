How it works

📱

Real-time Feed

Firestore stream ordered by creationDate pushes new videos to every connected device the instant they're uploaded — no polling, no refresh.

🗜️

On-device Compression

Before any byte leaves the phone, FFmpeg via video_compress shrinks the file to low-quality. Users get fast uploads; viewers get smooth streaming.

☁️

Firebase Backend

Compressed files land in Firebase Storage. The download URL and a timestamp go into Firestore under a UUID that links both records together.

🎥

Camera Pipeline

Long-press starts recording with a live circular progress indicator. Release stops it and shows a preview. A custom camera fork fixes audio recording on Android.

⬆️

Upload from Gallery

Tap the upload icon to pick any video from the device gallery. The same compression → Storage → Firestore pipeline runs automatically.

▶️

Vertical Swipe Player

A PageView with vertical scroll snapping auto-plays each video. Tap to pause, tap again to resume. Progress bar overlay shows position.
